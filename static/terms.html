서비스 약관

시행일: 2026년 8월 31일

1. 서비스 소개

Tokenbill(tokenbill.my)은 사용자가 등록한 API 키로 AI 프로바이더(OpenAI·Anthropic 등)의 사용량과 비용을 조회·시각화해 주는 무료 대시보드 서비스입니다.

2. 이용자의 책임

  • 본인 소유(또는 정당한 권한이 있는) API 키만 등록해야 합니다.
  • 계정 정보를 안전하게 관리할 책임은 이용자에게 있습니다.
  • 서비스에 대한 자동화된 남용(비정상적 대량 요청 등)을 금지합니다.

3. 데이터의 성격

표시되는 비용·토큰 수치는 프로바이더 API가 제공하는 데이터 기반의 참고용 요약이며, 실제 청구서와 차이가 있을 수 있습니다. 정확한 청구 금액은 각 프로바이더의 청구 내역을 확인하세요.

4. 서비스 제공

본 서비스는 무료로 제공되며, 사전 고지 없이 기능이 변경되거나 중단될 수 있습니다. 서비스 이용으로 발생한 손해에 대해 운영자는 고의·중과실이 없는 한 책임을 지지 않습니다.
