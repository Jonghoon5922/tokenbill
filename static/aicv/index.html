1MCP 설치 — 사용하는 AI 도구 선택

claude mcp add aicv -- npx -y github:Jonghoon5922/aicv

터미널에 붙여넣기 한 줄이면 끝 (Node 18+ 필요). Cursor 등 다른 MCP 지원 도구도 등록 가능합니다.

3이력서 만들기 ✓ 데이터 수집 중

연결된 AI 세션에서 이렇게 말하면, 내 작업 로그를 근거로 이력서 초안을 쓰고 내가 확인한 것만 발행됩니다:

"AI 활용 이력서 만들어줘"

이후엔 자동 — AI를 쓸 때마다 지표가 갱신되고, 문장은 "이력서에서 ○○ 고쳐줘" 한마디로 수정됩니다.

4공개 설정 ✓ 공개 중

프로필 주소(토큰명)는 자동 생성됩니다 — 공개 여부만 선택하세요 (기본 비공개).
