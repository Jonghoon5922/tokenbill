AICV

많이 썼다(리더보드)도, 시험 쳤다(자격증)도 아닌 — 실제 작업 로그가 AI 활용 능력을 증명합니다. 지속 업데이트되는 이력서.

시작하기

1. MCP 설치

①사용하는 AI 도구를 선택해 아래 한 줄 실행 (Node 18+ 필요):
claude mcp add aicv -- npx -y github:Jonghoon5922/aicv

그 외 MCP 지원 도구(Cursor 등)도 stdio 서버 등록 방식으로 사용할 수 있습니다.

2. 계정 연결

코드를 발급받아 AI에게 이렇게 말하세요: "aicv 연결해줘, 코드 XXXXXX" — 연결하면 이후 AI를 쓸 때마다 프로필이 자동 갱신되고, 이력서 문장은 원할 때만 다시 씁니다.

──────
고급: 토큰 직접 등록 
아직 발급 전

등록: claude mcp add aicv -- npx -y github:Jonghoon5922/aicv --token ...

3. 공개 프로필

프로필 주소(토큰명)는 가입 시 자동 생성됩니다. 공개 여부만 선택하세요 (기본 비공개 — 끄면 아무도 못 봅니다).

마지막 업로드: 없음 · 로그아웃 · 계정 삭제

어떻게 동작하나요?

수집MCP가 내 PC의 AI CLI 사용 로그를 스캔 — 대화 원문 없이 집계값만 (직접 만든 스킬·기술 스택·활용 사례 후보)
작성내가 쓰는 AI(Claude Code·Codex·Gemini CLI 등 MCP 지원 도구)가 그 증거를 근거로 이력서 초안을 쓰고, 내가 확인한 것만 올라갑니다
증명공개 프로필 링크 하나로 공유 — 이후 AI를 쓸 때마다 지표가 자동 갱신되고, 문장은 "고쳐줘" 한마디로 부분 수정

프라이버시: 대화 원문·실제 경로는 서버로 전송되지 않으며, 포함된 팩은 서버가 거부합니다. 프로필은 기본 비공개입니다.
