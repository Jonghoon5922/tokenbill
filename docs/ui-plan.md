# UI 개편 계획 — 첫 화면 다이어트와 탭 구조 (tokenbill/T005)

배경: 로그인 직후 카드 11개가 같은 무게로 나열되고, 투트랙 분리로 빈 카드가 화면 절반을
차지하며, 헤더 버튼이 10개다. 목표는 "내 AI 토큰, 한 화면에서"에 걸맞는 홈 + 탭 구조.

**진행 방식**: 페이즈 하나 = 커밋 하나 = 배포 하나. 각 페이즈는 독립적으로 배포 가능해야 하며,
끝나면 이 문서의 체크박스를 갱신한다. 토큰이 부족하면 다음 세션이 여기서 이어받는다.

## 지켜야 할 것 (모든 페이즈 공통)

- 대상 파일은 `static/index.html` 하나 (서버 API 변경 없음)
- i18n: 정적 문구는 `EN_TEXT` 사전(+localize 워커), 동적 문구는 `tr(ko, en)` — 기존 방식 유지
- 기존 렌더 함수(render/renderDaily/renderModels/renderLeaderboard/…) 시그니처는 유지하고
  **DOM 재배치 위주**로 작업. 로직 재작성 금지
- 유지해야 할 동작: /u/{id} 프로필 라우트·모달, 공지 팝업, 온보딩 카드, 임퍼소네이션 배너,
  viewerBtn/duetBtn의 생존 감지, localStorage 키들(tokenbill-token/-lang/-notice-seen/-admin-token)
- 배포 절차: JS 문법 체크(new Function) → commit/push → Actions 완료 확인 → 서버 docker 재배포
  (env: SECRET_KEY·GITHUB_TOKEN·ADMIN_EMAIL·GOOGLE_CLIENT_ID·AUTH_GOOGLE_ONLY·AICV_SECRET_KEY·AICV_DATABASE_URL)
  → 브라우저 스크린샷 검증(한/영 × 연동/미연동)

## P1 — 헤더 다이어트 [x]

버튼 10개 → 3그룹. `<details class="menu">` 기반 드롭다운(JS 최소, 바깥 클릭 시 닫힘 헬퍼 하나).

- `[🧰 도구 ▾]`: 대화 뷰어 / 작업 보드 / AICV — 기존 id(viewerBtn·duetBtn)와 클릭 로직 그대로
  드롭다운 항목으로 이동
- `[내 계정 ▾]`: 마이페이지 / 가이드 / 피드백 / 관리자(조건부) / 🌐 언어 / 로그아웃
- 월 내비게이터는 그대로. EN_TEXT에 새 라벨 추가, 없어진 라벨 정리는 P4에서

## P2 — 탭 골격 + 홈 탭 [x]

- 헤더 아래 탭 바: **홈 / 사용량 / 리더보드** (URL 해시 #home/#usage/#lb, 마지막 탭 localStorage 기억)
- dashView 내부를 `<div id="viewHome|viewUsage|viewLb">` 3개로 나누고 기존 섹션을 **이동만** 한다
  - 홈: 히어로(이번 달 토큰 크게 + 티어·순위 + 활동일 한 줄 요약) + 최근 14일 미니 차트(양 트랙 합산,
    renderDaily 재사용) + 리더보드 top3 요약(더보기 → 리더보드 탭) + 연동 상태 한 줄
  - 미연동 사용자는 홈 = 온보딩 카드 (기존 renderOnboard 그대로, 위치만 홈)
  - 사용량: 일별·모델별 차트 4개, 프로바이더 2카드, 인사이트, AI 통계 (P3에서 정리)
  - 리더보드: 기존 리더보드 카드 전체 폭으로
- render()는 전 탭을 그리되, 숨김 탭은 display:none (성능 문제 없음 — 현재도 전부 그림)

## P3 — 사용량 탭 차트 통합 [x]  (프로바이더 카드 접힘은 보류 — 키 등록 UI가 있어 상시 노출 유지)

- "일별 사용량" 카드 1개: 헤더에 ✅API/🖥️구독 트랙 토글 + (API일 때만) 토큰/비용 토글.
  기본 선택 = 이번 달 토큰이 있는 트랙
- "모델별 사용량" 카드 1개: 같은 트랙 토글 방식
- 빈 트랙은 토글로만 접근(빈 카드 상시 노출 제거), 프로바이더 카드도 데이터 없으면 접힘(한 줄)
- 기존 renderDaily(map, provs, chartId, …) 재사용 — 호출부만 트랙 상태에 따라 분기

## P4 — 통일 규칙 패스 [ ]

- 카드 헤더 규격: 제목(이모지 0~1) + 우측 액션 최대 1개. h2 안의 토글은 카드 상단 툴바로
- 제목 이모지 정리: 트랙 배지(✅/🖥️)와 브랜드성(🏆/📣)만 남기고 제거
- 타이포/여백 스케일 정리(변수화), 관리자 화면·모달 5종 톤 맞춤
- EN_TEXT에서 죽은 키 제거, 새 문구 보강
